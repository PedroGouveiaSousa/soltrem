SOLTREM

Extrai o ZIP e abre index.html num navegador para rever o site.
Para o commit, copia estes ficheiros para a pasta que o teu GitHub Pages já publica. Mantém a pasta assets junto do index.html.

O QR deve abrir a página inicial no endereço público do teu GitHub Pages. Antes de imprimir, abre esse endereço num telemóvel e confirma que ambos os menus abrem.

Bebidas usa a imagem 3 e Comidas usa a imagem 4. Os PNG estão incluídos com a resolução original. A página inicial usa miniaturas para carregar mais depressa.
